# Handing over to Claude Code

1. Create an empty folder (or a new GitHub repo) called `bradda-dads-site`.
2. Put `CLAUDE.md` in the root.
3. Create a `design` folder and put `homepage-mockup.dc.html` inside it.
4. Open the folder in Claude Code and paste this as your first message:

> Read CLAUDE.md and design/homepage-mockup.dc.html. Then work through milestone 1 and 2 only: scaffold the Astro project with Netlify config, design tokens, self-hosted fonts, base layout, header and footer, then the content collections with schemas, sample placeholder content and site.yaml. Show me the plan before you start, ask before adding any dependency not listed, and finish by running the dev server build and summarising what's done and what's next.

5. After that, carry on one milestone at a time ("Do milestone 3").
6. When you're ready for other committee members to edit (phase 2), say: "Do the phase 2 checklist in CLAUDE.md."
