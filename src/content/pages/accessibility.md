statement: |-
  ## What we aim for

  This website aims to meet the [Web Content Accessibility Guidelines (WCAG) 2.2](https://www.w3.org/TR/WCAG22/) at level AA, the standard most UK organisations work to.

  You should be able to:

  - use every part of the site with a keyboard alone, with a clear outline showing where you are
  - use it with a screen reader, such as VoiceOver, TalkBack or NVDA
  - zoom in up to 400% without text overlapping or the page scrolling sideways
  - read all text against its background (every colour pair meets the WCAG contrast ratio)
  - turn off animations: if your device is set to reduce motion, the bobbing ducks and sliding effects stop
  - see when every photo was taken, and read a description of the main photos

  ## How we check

  Every time the site changes we run checks on each type of page, at phone and desktop sizes:

  - automated accessibility testing (axe-core, against WCAG 2.2 A and AA)
  - keyboard testing of the menus, photo viewer, results tables and events carousel
  - colour contrast checks on every text and background colour the site uses
  - layout checks at phone widths down to 320 pixels

  ## What isn't finished yet

  - **Photo descriptions.** {photo-descriptions} Descriptions of older photos were written from the pictures themselves, so if one is wrong, please tell us.
  - **Original race results.** Some race years link to the original results PDF from the race organiser. These may not work well with screen readers, but the same results are on the site as a searchable table, and as a spreadsheet you can download.
  - **The map.** The "where the money goes" map can be hard to use without sight or a mouse, so every place on it is also listed underneath in plain text.
  - **Older news stories.** Stories from 2001 to 2024 were brought across from our old websites as they were written, so a few may link to pages that no longer exist.

  ## Tell us about a problem

  If something on the site doesn't work for you, or you need information in a different format, please [get in touch](/contact/). Tell us the page and what went wrong. We're volunteers, but we'll reply as soon as we can and fix what we can.
updatedNote: This statement was written on 21 November 2026, when the site was last fully tested.
